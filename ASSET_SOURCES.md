## Marketing photography
The landing page uses a Pexels-hosted image URL for the African student hero/photo treatment. The source page identifies the image as free to use and tags it as Nigeria/Nigerian student photography:
https://www.pexels.com/photo/african-student-in-school-uniform-smiling-outdoors-31118300/

If you want the production site to be completely self-contained, replace the remote `heroImage` URL in `app/page.js` and the matching CSS background URL in `app/globals.css` with a locally licensed image.
