# Edvora database

Use `EDVORA_COMPLETE_SCHEMA.sql` for a fresh Supabase project. It is self-contained and includes the V2 core schema, V3 production tables, V4 workflows, and V9 security hardening.

Use `EDVORA_TENANT_SECURITY_TESTS.sql` separately in a controlled test project after creating test tenants/users.

Never expose `SUPABASE_SERVICE_ROLE_KEY` to the browser.
