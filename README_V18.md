# Edvora V18

V18 is the production-hardening release built on the V17 codebase.

## Major upgrades

- Canonical CA → exam → weighting → grade → ranking → report-card → publication → locking engine.
- Separate fullscreen Edvora CBT examination environment.
- CBT autosave, local offline queue, reconnect sync, timer, integrity events and secure result visibility.
- Finance idempotency/reconciliation foundations and provider-reference uniqueness.
- Security events, session-device records, integration health and observability events.
- V18 SQL RLS policies and static security checks.
- V18 syntax and production validation scripts.

## Important

Live Supabase validation, browser E2E and Vercel deployment verification require the target environment credentials and a browser/deployment environment. The included checks deliberately do not claim those are verified locally.
